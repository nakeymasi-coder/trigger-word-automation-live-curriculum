# Trigger Word Automation — Live Curriculum

Glam's student curriculum (Fall Freaknik edition): turn one comment into a customer conversation. Buyers learn the trigger word automation system step by step — what a connector is, how to connect their apps in Muse first, how TikTok and YouTube get worked through the cloud browser prompt since they have no connector, the sent log piles (Original / Nudge / Skip), and the batch approval gate — with a copy-ready setup prompt, a playable Trigger-Word Simulator, and a Sort the Pile game.

**Live page:** https://nakeymasi-coder.github.io/trigger-word-automation-live-curriculum/

Installable: open the live page on a phone and choose "Add to Home Screen" — it installs with its own icon and opens full-screen like an app. Fully responsive and mobile friendly.

## Files

- `index.html` — the whole curriculum, one self-contained page (photos inlined)
- `manifest.webmanifest` — install manifest (name, icons, colors)
- `icon-512.png`, `icon-192.png`, `apple-touch-icon.png`, `favicon-32.png` — the curriculum's icon set (burnt-orange comment bubble, cream maple leaf, gold ring, brown plaid)
